# S4 C API

The C API is currently transitioning from the original, unclean form to a more streamlined form with opaque objects.
Please refer to `S4.h` for the upstream/full C API (still subject to change).

**For simulation_core:** the stable C surface is `S4/s4_bridge.h` (`s4_bridge_*`), not the full `S4.h` surface. See the top-level `README` in this submodule.
